### Perfil

Desarrollador Web enfocado en la creación de experiencias digitales modernas, eficientes y visualmente cuidadas. Trabajo principalmente con tecnologías web como HTML5, CSS3 y JavaScript, complementándolas con herramientas y frameworks como Tailwind CSS, Astro y React.
